Computes EIP-712 data to be signed to create a sto

Computes EIP-712 data to be signed to create a stop-loss / take-profit strategy that monitors a token's price and swaps it when a threshold is hit.

Request Body schema: application/json
required
chainId
required
integer

Chain ID where the position exists

tokenIn
required
string

Token being monitored and sold when a threshold is hit. Use 0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE for native token.

tokenOut
required
string

Token to receive after the swap. Use 0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE for native token.

stopLossPrice
string

USD price per tokenIn at or below which to trigger a stop-loss swap, e.g. "1500.00". Omit to disable. At least one of stopLossPrice or takeProfitPrice is required.

takeProfitPrice
string

USD price per tokenIn at or above which to trigger a take-profit swap, e.g. "3000.00". Omit to disable. At least one of stopLossPrice or takeProfitPrice is required.

wallet
required
string

Address whose balance is monitored and from where the funds will be pulled

balanceBps
required
integer [ 0 .. 10000 ]

Fraction of the tokenIn balance to swap, in basis points (e.g. 10000 = 100% (full balance), 3330 = 33.3%)

slippageBps
required
integer [ 0 .. 10000 ]

Slippage tolerance for the swap, in basis points (e.g. 50 = 0.50%)

recipient
string

Address that receives the tokenOut. Defaults to wallet.

feeAmount
string

Max fee in USD. Defaults to 0.

Computes EIP-712 data to be signed to rebalance a portfolio to target token allocations, either once or as a recurring strategy.

Request Body schema: application/json
required
chainId
required
integer

Chain ID where the portfolio exists

required
Array of objects >= 2 items

Target allocation for each token. targetBps values must sum to 10000 (100%).

wallet
required
string

Address whose portfolio is rebalanced — holds the funds and receives the output

slippageBps
required
integer [ 0 .. 10000 ]

Slippage tolerance for the swaps, in basis points (e.g. 50 = 0.50%)

driftToleranceBps
integer [ 0 .. 10000 ]

Minimum deviation from a token's target allocation required before it is rebalanced, in basis points (e.g. 10 = 0.10%)

frequency
string
Enum: "hourly" "daily" "weekly" "monthly"

How often the portfolio is checked and rebalanced (if needed). Omit to rebalance once, immediately.

endDate
integer

Timestamp after which the strategy stops executing. Only relevant when frequency is set. Use 0 for no end date. Defaults to 0.

feeAmount
string

Max fee in USD. Defaults to 0.
